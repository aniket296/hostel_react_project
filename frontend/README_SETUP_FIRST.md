# Beginner setup notes for current frontend build

This frontend is the current React-conversion frontend build.

What it is now:
- React + Vite starter
- Login flow scaffold
- Role-based routes scaffold
- Pages wired to starter backend API endpoints

What it is not yet:
- Not yet a guaranteed 100% parity copy of every original Django template flow

Run order later:
1. Install Node.js
2. Run npm install
3. Create .env from .env.example
4. Start Vite dev server on port 5173
